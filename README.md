# zepto_customer_analysis


Project Overview

This project focuses on analyzing Zepto product inventory and pricing data using SQL. It demonstrates practical SQL skills through data exploration, data cleaning, and business-oriented analysis to uncover insights into product pricing, discounts, stock availability, inventory weight, and estimated revenue across product categories.

Objectives

- Explore product inventory data and understand its structure.
- Identify missing values, duplicate product names, and invalid pricing records.
- Clean and standardize product pricing data.
- Analyze discounts and identify the best-value products.
- Evaluate stock availability and high-priced out-of-stock products.
- Calculate estimated revenue and inventory weight by category.
- Analyze product weight and price per gram to identify value-for-money products.

 Tools & Technologies

- SQL
- MySQL / MySQL Workbench
- Aggregate functions, filtering, sorting, and grouping
- `CASE` statements, subqueries, and data manipulation queries

 Key Analysis Performed

1. Data Exploration: Examined record counts, sample records, product categories, and stock distribution.
2. Data Cleaning:Identified missing values, checked for zero-priced products, and standardized prices from paise to rupees.
3. Discount Analysis: Identified the top 10 products with the highest discount percentages and categories with the highest average discounts.
4. Inventory Analysis: Examined out-of-stock products with high MRP and calculated total inventory weight by category.
5. Pricing Analysis: Identified products with high MRP and low discounts and calculated price per gram for products weighing at least 100 grams.
6. Product Segmentation: Classified products into Low, Medium, and Bulk weight categories using conditional logic.

 Business Insights

This project uses SQL queries to support business questions such as:

- Which products offer the highest discounts?
- Which categories provide the highest average discounts?
- Which expensive products are currently out of stock?
- Which categories have the highest estimated inventory revenue?
- Which products offer better value based on price per gram?
- How is inventory weight distributed across product categories?

 Skills Demonstrated

SQL querying, data cleaning, data validation, aggregation, business analysis, inventory analysis, pricing analysis, and analytical problem-solving.

Conclusion

The project demonstrates how SQL can transform raw product data into structured information for business analysis and decision-making. It serves as a practical portfolio project showcasing foundational data analytics skills using MySQL.
